# This is a simple CRUD Back End using Go & SQL Server and Project IDX ready.

## Steps to setup:

1. Go to [Project IDX](https://idx.google.com/import) (import section).
1. Paste this link: `https://github.com/rizkiagussalim/starter-BE-Go-MSSQL` (or your fork of it).
1. Wait for your environment to start.
1. Copy and paste the `.env-template` file to `.env`, then update the database credentials according to your setup.
1. To run this project, execute the following command in the terminal:

   ```sh
   go run main.go
   ```

1. Open the `test-api.http` file and click `Send Request` to test the API.
1. Now you can start experimenting with Go and SQL Server using this starter project.

Have fun coding!
